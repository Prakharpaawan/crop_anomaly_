## Building it

compiled.

**Overleaf (easiest).** New Project → Blank Project → upload `main.tex`,
`refs.bib` and the `figures/` folder → compiler pdfLaTeX. `IEEEtran.cls` ships
with Overleaf.

**Locally**, after installing MiKTeX or TeX Live:

```bash
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

Float-placement warnings on the first pass are normal for IEEE two-column with
this many exhibits.

## What changed in this rewrite

The earlier draft was built on `hybrid_pipeline_experiments2/` and one of its
three contributions turned out to be wrong. The rewrite:

| | Old draft | Now |
|---|---|---|
| Headline | F1 0.718, adaptive P85 | **F1 0.844**, EVT threshold, held-out fields |
| Contribution 2 | operating-point analysis | **threshold placement beats detector choice** (+0.151 F1) |
| Contribution 3 | "protocol explains a 0.72→0.35 drop" | **withdrawn** — controlled test puts it at 0.021 F1 |
| Protocol | fit and report on the same fields | three-way disjoint split; nothing selected on test |
| Persistence | sliding window called non-causal | corrected — it is causal |
| Title | "…and the Cost of Evaluation Protocol" | "…and the Primacy of Threshold Calibration" |

The ensemble negative result survives and is stronger: LOF 0.844 against 0.354
for the hybrid, and the mechanism is now identified as a **recall** collapse
(0.814 → 0.230), not a precision failure.

## Before submitting

- **Fill in the author block** — it reads `[Author Name]` etc.
- **Cite the data source.** §III describes the Lombardy archive but nothing
  cites where it came from. If it has a paper, dataset DOI or portal, add it —
  a reviewer will ask.
- **Verify the bibliography.** 28 entries, standard works, but volume/issue/page
  numbers should be spot-checked against publisher records.
- **The p-value is reported at the resolution limit** of a 2,000-permutation
  test ($p < 5\times10^{-4}$), not as a point estimate. Don't tighten it without
  running more permutations.
- **Two claims are deliberately unflattering** and should stay: the recommended
  operating point is *worse* than its predecessor below 30% severity (§V-D), and
  the injection mechanism is generous to the detector (§VII). Removing them
  would make the paper weaker under review, not stronger.

## Known soft spots

A reviewer will press on these; they are stated in the paper rather than hidden:

- **No ground truth.** Every number rests on synthetic injection, and the
  injection perturbs six of the sixteen features directly — a large coherent
  displacement in exactly the detector's feature space.
- **Works where it matters least.** Reliable above 30% severity; F1 0.08–0.48 at
  10–20%, which is where early warning has value.
- **Clean calibration needs a stress-free reference period** per field, which a
  real-time system does not have.
- **One region, one season.** No transfer evidence.
